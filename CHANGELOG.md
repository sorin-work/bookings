# Changelog

## 1.0.0 (2026-11-07)

First release. Everything below has been in use for a while; this marks the point where
the feature set is complete enough for a small business to run on.

- Public booking page per business with services, staff choice and free times that
  respect working hours, time off, buffers, minimum notice, closed days and the
  booking window.
- Booking links for customers to confirm, cancel or move a booking, with a
  cancellation notice period.
- Emails for every booking event, with calendar files, reminders a day before and
  copies for staff.
- Staff calendar with day and week views, a booking panel, outcomes and bookings added
  by hand.
- Dashboard with today's appointments, revenue, cancellation and no-show rates, top
  services and weekly bookings.
- Bookings list with search, filters and CSV export; customer list and history.
- Private calendar feeds for staff.
- Docker Compose setup with Postgres and mailpit, demo data, GitHub Actions CI.
